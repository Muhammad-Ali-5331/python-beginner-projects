# Python Beginner Projects

Early Python fundamentals projects: console apps, simple OOP, and small Tkinter/GUI exercises, each in its own subfolder.

## Contents

- `Miles to Km Converter/`
- `NATO Alphabet Converter/`
- `Cofee Machine/`
- `OOP Coffee Machine/`
- `Quiz Game/`
- `The Quizzler App/`
- `The Cookie Clicker/`
- `Habit Tracker/`

Each subfolder is a standalone mini-project with its own `main.py` (run independently).

## Tags

`python-basics`, `oop`, `tkinter`

## Note

This project was built while learning Python. Some scripts may reference API keys, email credentials, or local file paths — replace placeholders with your own values (ideally via environment variables / a `.env` file) before running.
